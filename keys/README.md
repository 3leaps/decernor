# Release signing pins

`expected-fingerprints.txt` is the verifier contract. It is generated by
`make release-insert-anchors` from `decernor fingerprint` on **exported
public** files. Hex is never hand-typed.

`expected-fingerprints.ndjson` is the matching DDR-0001 receipt.

Do not commit private keys, keystore trees, or public key files here.
Public `.pub` / `.asc` files ride the GitHub release only.

Bindings are environment variables (`DECERNOR_MINISIGN_PUB`,
`DECERNOR_GPG_HOMEDIR`, `DECERNOR_PGP_KEY_ID`). No paths in this tree.
