# v0.1.6 — 2026-08-25

Decernor is available through the official 3 Leaps package repositories:

```sh
brew install 3leaps/tap/decernor
```

```powershell
scoop bucket add 3leaps https://github.com/3leaps/scoop-bucket
scoop install decernor
```

This release adds package-manager handoff checks that require a published,
stable GitHub release with matching archive digests before updating the
Homebrew formula and Scoop manifest. The handoff only writes the sibling
worktrees; it never stages, commits, pushes, or needs signing credentials.

Package managers remain a convenience distribution path. Verify signed GitHub
release assets and the fingerprint pins for the full provenance path.
