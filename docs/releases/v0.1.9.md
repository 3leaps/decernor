# v0.1.9 — 2026-10-12

This release classifies GnuPG agent key files by content. A GnuPG home whose
secret keys live on a smartcard or TPM no longer reports its shadow stubs as
plaintext secret keys. Committed signing anchors are unchanged from v0.1.8.

## GnuPG agent key files

Files in `private-keys-v1.d/`, in the extended and the legacy canonical
format, are classified by their outer key form:

| Content                      | Code                         | Classification         |
| ---------------------------- | ---------------------------- | ---------------------- |
| Plaintext secret key         | `GPG-AGENT-UNPROTECTED-KEY`  | `unsafe-secret`        |
| Passphrase-protected key     | `GPG-AGENT-PROTECTED-KEY`    | `protected-secret`     |
| Smartcard or TPM shadow stub | `GPG-AGENT-SHADOWED-KEY`     | `hardware-stub` (new)  |
| Anything else                | `GPG-AGENT-KEY-UNRECOGNIZED` | `parse-error` (unsafe) |

A stub is recognized only when it carries no secret parameters for its
algorithm. Ambiguous, truncated, or trailing content is unrecognized. Files
larger than the 32 KiB inspection prefix are read in full, up to
`--max-file-size`, when their content is an agent key file; a failed read
reports `SCAN-READ-ERROR`. `guardread` refuses every agent key file, and
`fingerprint` reports them as `unsupported-kind`.

## Profiles

`--profile workstation` now takes effect. GnuPG home internals (keyring
databases, agent stubs) are info instead of unsafe. Secret verdicts are the
same in both profiles, so a plaintext key fails either way. Under the default
`artifact` profile, a GnuPG home in an artifact is still a finding.
Keyring-internal directories are no longer skipped or reported as secret by
name. The scan descends into them and classifies each file. The directory
finding is `sensitive`, and in the default profile it is P2. The legacy
`secring.gpg` reports as `GPG-KEYRING-SECRET-FILE`. Scan reports include the
profile used, in the JSON `profile` field and the text header.

## Build and tests

The minimum Go version is 1.26.9. CI and release run the digest-pinned
`goneat-tools-runner-glibc:v0.5.9` (Go 1.26.9, Goneat v0.6.3). Agent key tests
read specimens and expected verdicts from the external fixture corpus
[`3leaps/synthcorpus`](https://github.com/3leaps/synthcorpus) at a pinned
commit, recorded in `testdata/synthcorpus.pin`; see
[PDR-0002](../decisions/PDR-0002-tests-consume-external-fixture-corpus.md).
